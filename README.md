# AI CV Screening

This is a simple CV Screening project.

The project helps to upload CVs and check candidates for a job.

## Features

* Create a job
* Upload a CV
* Read CV information
* Show candidates
* Show candidate details
* Check candidate skills
* Check experience
* Check education
* Calculate candidate score
* Show Tier 1, Tier 2 and Tier 3

## Technologies Used

### Frontend

* React.js
* Vite
* Tailwind CSS
* React Router
* JavaScript

### Backend

* Node.js
* Express.js
* JavaScript
* Multer
* PDF.js
* Mammoth
* CORS

### Data

* JSON Objects

## CV Files

The project supports:

* PDF
* DOCX
* TXT

## Candidate Score

The project checks:

* Skills
* Experience
* Education
* Certifications
* Industry

The candidate gets a score and a tier.

## How to Run

### Backend

```bash
cd backend
npm install
node server.js
```

### Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```
